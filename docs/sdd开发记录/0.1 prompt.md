2、整个执行流程能否编排成一个多智能体的形式呢？这样的话多个智能体各司其职，后续我们在优化也更有针对性，比如我现在的设想是：S4 是让大模型生成 SQL，这一步就完全可以搭建为一个独立的子智能体去对待，就可以称它为 Coder。那么在它之前做各种准备，你也可以规划一个或多个子智能体去负责处理。至于怎么去编排和实现你来决定，比如我以前经常听到 Langchain、Langgraph，是不是能用来实现呢？
